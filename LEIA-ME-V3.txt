PARA SUBSTITUIR A V2 LOCAL
1. Extraia o ZIP.
2. Copie TODOS OS ITENS DO INTERIOR desta pasta para seu diretório
   tm21-portfolio-2, substituindo os arquivos de mesmo nome.
3. Revise o site localmente, inclusive fotos e claims dos cases.
4. Na pasta já conectada ao repositório do Git, use:
   git add -A
   git commit -m "Atualiza portfolio V3 e imagens dos projetos"
   git push origin main
